## 📖 Overview

ASTRA-IST demonstrates early fault detection for sensors (e.g. thermistors) in avionics systems:
- Normal temperature telemetry may look standard while sensor degradation occurs.
- ASTRA-IST applies a controlled heat pulse and analyzes the response curve to detect anomalies before critical failure.

## 💻 Running Locally

Simply open `index.html` (or `astra.html`) in any modern web browser.
